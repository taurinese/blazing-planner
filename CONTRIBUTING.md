# Contributing / Contribuer

**FR** — Le code est public par souci de transparence, mais le projet n'accepte pas de pull requests (elles sont fermées automatiquement). Tu peux :

- ouvrir une **issue** pour signaler un bug ou une donnée incorrecte (élément, étoiles, coût d'éveil) ;
- forker le projet sous licence MIT pour ta propre version.

**EN** — The code is public for transparency, but pull requests are not accepted (they are closed automatically). You can:

- open an **issue** to report a bug or wrong game data (element, stars, awakening cost);
- fork the project under the MIT licence for your own version.
